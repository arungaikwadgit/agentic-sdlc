# Handoff — production bgColor crash + admin panel access fix (2026-07-08)

Session scope: two production issues on https://agentic-sdlc-delta.vercel.app,
unrelated to the old `.handoff-batch7.md` (that's a separate, older
remediation engagement — do not conflate the two).

## What shipped

**1. `DOMAINS[project.domain].bgColor` crash — commit `addb1823`**
Confirmed pushed to `origin/main` (user ran `git log --oneline -3` and it showed
`addb1823 (HEAD -> main, origin/main, origin/HEAD)`). This is live.

**2. Admin panel not visible at `/admin` in production — commit `b71d9e00`**
Root cause: `isAdminMode()` (`frontend/src/lib/adminMode.ts`) is hardcoded off
outside dev builds (`ADMIN_BYPASS_ENABLED = import.meta.env.DEV`), and there
was no production admin-recognition path at all.

Fix: new `frontend/src/services/adminAuth.ts` calls the existing, already-
reachable `GET /api/projects/permissions/me` on the `server/` service, wired
into `AuthContext` as `isAppAdmin`, gating `AdminPanel`/`ChatWidget` admin
mode in `App.tsx` and `AdminPanel.tsx` alongside the existing dev bypass.

**Bug caught and fixed during this work, not shipped:** first draft added a
new `GET /api/admin/whoami` route directly to `backend/src/proxy.js`. That
would have been dead code — `proxy.js` has `app.use('/api/admin',
forwardToServer)` registered earlier in the file, which forwards ALL
`/api/admin/*` traffic to the `server/` service before any later route in
`proxy.js` can run. Removed it; reused `server/`'s existing
`/permissions/me` endpoint instead. `proxy.js` has zero net diff from HEAD
as a result (confirmed via `git hash-object` match).

Committed to local `main`. **Status as of end of session: committed but NOT
confirmed pushed to `origin/main`.** User needs to run:
```
git push origin main
```

2. **`ADMIN_EMAIL_ALLOWLIST` Railway env var — set on the WRONG service.**
   User set it (`arun.gaikwad@gmail.com,arun.gaikwad@outlook.com`) on the
   Railway project `steadfast-flexibility / agentic-sdlc`, on the **proxy**
   service (runs `backend/src/proxy.js`, package name `agentic-sdlc-backend`).

   away to `server/` before proxy.js's own logic runs.

   mounted at `/api/projects/permissions/me` via `server/src/index.ts`).
   To find that service in Railway: check the `SERVER_API_URL` env var on
   the proxy service you already edited — its value is the URL of the
   correct `server/` service to add the allowlist to.
