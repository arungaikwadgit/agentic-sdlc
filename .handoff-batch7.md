## Known recurring sandbox bug (context for whoever picks this up)

Write/Edit tools sometimes silently fail to propagate to the bash-visible
filesystem (bindfs mount), causing mid-token truncation, trailing null-byte
padding, or duplicate-content splices, while still reporting success. Detection:
syntax errors where only logic errors should be, `wc -l`/`wc -c` mismatches,
`tail -c N | xxd`, `git show HEAD:<path>` diffing when git history exists. Recovery
hierarchy: git-diff-and-splice > reconstruct from already-Read content > full-file
heredoc rewrite as last resort after 3 failed Edit attempts on the same file.
